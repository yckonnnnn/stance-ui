# 布局、组件与状态

## 布局

页面先确定：

- 最大宽度。
- 栅格。
- 间距尺度。
- 区块节奏。
- 内容密度。

间距要有层级。区块间距应明显大于组内间距，否则页面会糊成一整块。

不要用 50% 宽度、复杂 calc 和绝对定位堆版式。优先使用网格。

## 卡片

只在卡片代表一个独立对象、可点击整体或真实层级时使用。

卡片不是万能容器。能用标题、分隔线和留白表达的关系，不要套卡片。

卡片内不要再套三层卡片。

## 按钮

- 主动作、次动作、危险动作有层级。
- 文字在桌面不换行。
- 对比度足够。
- 加载时宽度不跳。
- 禁用仍然可读。

## 输入

- 标签在上。
- 帮助文字可选。
- 错误在下。
- 失败不丢内容。
- 焦点环可见。
- 自动填充不破坏布局。

## 选择与开关

- 已选 / 未选 / 部分选中 / 不可用清楚。
- 键盘可操作。
- 长选项不溢出。

## 菜单与弹窗

- 打开后焦点进入。
- Esc 能关闭。
- 关闭后焦点回到触发位置。
- 手机上不能超出视口。
- 关闭时对未保存内容有明确处理。

## 表格

表格用于需要横向比较的数据。

移动端先决定：

- 横向滚动。
- 转成卡片。
- 只保留关键列。
- 进入详情查看完整信息。

不要直接把桌面表格压到手机。

## 设计变量

至少定义：

- 字体。
- 字号。
- 行高。
- 间距。
- 圆角。
- 边框。
- 阴影。
- 颜色。
- 动效时长。

所有页面从同一组变量取值。
