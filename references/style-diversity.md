# 风格多样性

## 为什么需要

AI 很容易把上一次成功的页面当成下一次的默认值。结果是每个项目都变成同一种：

- 纸张底色。
- 衬线大标题。
- 橙色重点。
- 细线网格。
- 左右分栏。

这不是品牌，是惯性。

## 风格不是随机

先看证据：

- 品类。
- 用户。
- 品牌已有资产。
- 页面要完成的动作。
- 内容密度。
- 使用环境。

风格应该从这些条件里长出来。

## 八个可用家族

### 1. 编辑型

适合：杂志、文化、出版、研究、作品集。

特征：文字节奏、标题层级、图片与正文关系。

风险：被滥用成所有产品的“高级默认”。

### 2. 工业实用型

适合：开发者工具、基础设施、物流、制造、工程。

特征：紧凑网格、等宽数字、状态色、信息密度高。

风险：容易变成荧光色黑底控制台。

### 3. 仪器型

适合：监控、金融、分析、硬件。

特征：读数、刻度、图表、时间线、精确状态。

风险：过度拟物或信息过载。

### 4. 冷静极简型

适合：效率工具、企业产品、专业服务。

特征：中性色、清晰层级、少量视觉装饰。

风险：缺少辨识度，像通用 SaaS。

### 5. 温暖人本型

适合：健康、教育、家庭、社区、个人服务。

特征：自然材质、柔和形状、清楚的语言。

风险：滑向通用的米色疗愈风。

### 6. 鲜明消费型

适合：娱乐、社交、生活方式、零售。

特征：强色块、大图、动态构图、明确动作。

风险：只热闹，没有任务层级。

### 7. 黑标精品型

适合：珠宝、香氛、酒店、建筑、定制服务。

特征：深色、克制、材质和留白。

风险：用深色和衬线硬装高级。

### 8. 实验表现型

适合：创意工具、音乐、游戏、活动、个人表达。

特征：非对称、动态排版、特殊网格、非常规节奏。

风险：视觉压过内容，手机失控。

## 选择方法

先选一个主家族，再最多加入一个辅助特征。

例如：

- 工业实用型 + 编辑型标题。
- 仪器型 + 温暖人本型语言。
- 冷静极简型 + 实验表现型网格。

不要同时混合五种语言。

## 风格轮换门

产出前至少改变三个维度：

| 维度 | 问题 |
| --- | --- |
| 主色调 | 除了黑白，主色是否来自产品而不是上一页 |
| 字体性格 | 是否换了字体关系，而不是只换字号 |
| 版式结构 | 是否改变了首屏构图和信息节奏 |
| 形状语言 | 圆角、边框、材质是否属于同一套新规则 |
| 图像语言 | 图片承担什么，而不是有没有图片 |
| 动效 | 是否只在该产品需要时出现 |

三个维度以上相同，重做。

## 禁止复用 Zack UI 官网外观

除非用户明确要求，否则不要把下面这套当作默认：

- 纸张底色。
- 信号红 / 橙色强调。
- 大号衬线标题。
- 硬边框、细线网格和编辑式分栏。
- 深绿监控台。

它属于 Zack UI 品牌，不属于客户的页面。

## 判断是否真的不同

遮住 logo、标题和文案，只看构图与材质：

- 还认得出是另一个产品吗？
- 换一个行业后还成立吗？
- 是否只是把同一张页面换成了不同文字？

如果答案不成立，继续改。
