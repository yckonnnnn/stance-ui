# 常用提示词

## 新网站

```text
用 Zack UI 设计这个产品的官网首页。
先读真实产品、用户和现有内容，不要直接写页面。
先给我三个明显不同的方向，每个方向只做首屏。
说明各自适合什么，我选定后再完成整页。
最后在 1440px 和 390px 下打开检查。
```

## 新 App

```text
用 Zack UI 设计这个 App 的核心三屏。
先写清核心循环、导航模型和主要动作。
先给我三套不同的首页方向，再做详情和结果页。
补齐空、加载、错误和成功状态。
最后按 390×844 检查真实操作。
```

## 改版

```text
用 Zack UI 审查并改进这个现有页面。
先读现有页面、组件和样式，不要直接改。
列出最影响使用的三个问题，再提出整理、升级和改流程三层方案。
我确认范围后再动手。
```

## 单组件

```text
用 Zack UI 精修这个组件。
把它放回真实任务里，不要只做默认状态。
补齐悬停、聚焦、按下、加载、禁用、错误和成功。
检查手机宽度和 200% 放大。
```

## 视觉评审

```text
用 Zack UI 评审这个页面，先不要改代码。
打开真实页面，在桌面和手机宽度检查。
问题按严重程度排序，每个问题写清位置、原因和具体修法。
```
